# Terminal-Bench V2 Tasks

Terminal-Bench V2 task suite for AI coding agent benchmarking.

## Tasks

| Task | Description |
|------|-------------|
| `kernel-memory-leak-analyzer` | Analyze kernel memory leak telemetry and produce structured findings |
| `sandbox-escape-block` | Detect and block sandbox escape attempts from case datasets |
| `segment-manifest-recovery` | Recover and validate segment manifests from sealed artifacts |
| `service-trust-boundary-analyzer` | Analyze service trust boundaries from capture datasets |

Each task includes `instruction.md`, `task.toml`, `environment/`, `solution/`, and `tests/`.
