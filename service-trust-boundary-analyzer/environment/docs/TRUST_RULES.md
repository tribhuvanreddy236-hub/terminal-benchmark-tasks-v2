# Service trust boundary policy (read-only specification)

Implement these rules in Go under `/app/cmd` and `/app/internal` only; do not edit this file or other files under `/app/docs/`.

Fixtures live under `/app/data` as `dataset_XX.json` (01–20) plus `/app/data/dataset_XX/capture.pcm` (PCM1 little-endian per `CAPTURE_FORMAT.md`). JSON files hold scenario defaults only (no `events` array). `/app/data/manifest.json` lists `scenarios` in processing order.

## Scenario defaults

- `require_token_on_internal` (bool, default true when the field is omitted from JSON)
- `block_partner_to_privileged` (bool, default true when omitted)
- `policy_overrides` (optional): may override either boolean above

Apply `policy_overrides` on top of defaults before replay.

## Event ordering and deduplication

Sort events ascending by `(seq, service_id, event_id)`. Drop later rows with a duplicate `event_id` (first wins). Count skipped duplicates in `duplicate_events_skipped`.

For `ALLOW_TRUST`, `REVOKE_TRUST`, and `SERVICE_CALL`, set `service_id` to `to_service` (the callee) for sorting.

## Service state

Per `service_id`: `tier` (`internal`, `partner`, or `privileged`), `capabilities` (set of strings from `BIND_CAPABILITY`).

## REGISTER_SERVICE

Fields: `service_id`, `tier`.

If `service_id` already exists → `DUPLICATE_SERVICE` (no mutation). Else create service with empty capabilities.

## ALLOW_TRUST

Fields: `from_service`, `to_service` (both non-empty).

If either endpoint is unknown → `UNKNOWN_CALLER` when `from_service` is missing (`entity_id` = `from_service`, `detail` = event kind); else `UNKNOWN_CALLEE` (`entity_id` = `to_service`, `detail` = event kind).

If directed edge `from_service→to_service` already exists → `DUPLICATE_TRUST` (`entity_id` = `to_service`, `detail` = `from_service`). Else record the edge.

## REVOKE_TRUST

Fields: `from_service`, `to_service`. Unknown endpoints → same as `ALLOW_TRUST`. If edge absent → no finding. Else remove edge.

## BIND_CAPABILITY

Fields: `service_id`, `capability` (non-empty).

Missing service → `UNKNOWN_CALLER` (`entity_id` = `service_id`, `detail` = event kind). Else add capability (idempotent).

## SERVICE_CALL

Fields: `caller_id`, `callee_id`, `action`, `has_token` (bool), `propagated_capabilities` (array), optional `original_caller` (default `""`).

Evaluate in order; **stop** further checks for this event after emitting `UNKNOWN_CALLEE`, `UNKNOWN_CALLER`, `UNTRUSTED_PEER`, `RESTRICTED_ESCALATION`, or `UNVERIFIED_CALLER`.

1. Missing `callee_id` registration → `UNKNOWN_CALLEE` (`entity_id` = `callee_id`, `detail` = event kind).
2. Missing `caller_id` registration → `UNKNOWN_CALLER` (`entity_id` = `caller_id`, `detail` = event kind).
3. No `ALLOW_TRUST` edge `caller_id→callee_id` → `UNTRUSTED_PEER` (`entity_id` = `callee_id`, `detail` = `caller_id`).
4. Caller tier `partner`, callee tier `privileged`, and `block_partner_to_privileged` → `RESTRICTED_ESCALATION` (`entity_id` = `caller_id`, `detail` = `callee_id`).
5. Callee tier `internal`, `require_token_on_internal`, and not `has_token` → `UNVERIFIED_CALLER` (`entity_id` = `callee_id`, `detail` = **empty**).
6. Each entry in `propagated_capabilities` must be present on the caller’s bound capabilities. On first violation → `PRIVILEGE_ESCALATION` (`entity_id` = `caller_id`, `detail` = first missing capability in **sorted** order). Emit **at most one** `PRIVILEGE_ESCALATION` per `(caller_id, capability)` per scenario (track `caller_id::capability`).
7. If `original_caller` is non-empty, `original_caller != caller_id`, and any propagated capability is absent from the caller’s set → `LATERAL_MOVEMENT` (`entity_id` = `original_caller`, `detail` = first such capability in sorted order).

## Post-replay audits (after all events)

Use `event_seq` = max event `seq` in the scenario plus one for audit-only findings.

**MESH_ASYMMETRY** — For each `ALLOW_TRUST` edge with `from_service` tier `partner` and `to_service` tier `internal`, if there is no `ALLOW_TRUST` edge from that `to_service` back to the same `from_service`, emit one finding (`entity_id` = `to_service`, `detail` = `from_service`). At most one per directed partner→internal pair.

**OPEN_PRIVILEGE_PATH** — For each `privileged` tier service that has an inbound `ALLOW_TRUST` from any `partner` tier service, if `mesh:audit` is not in that service’s capabilities, emit (`entity_id` = privileged `service_id`, `detail` = lexicographically first such `partner` `service_id`). At most one per privileged service.

**ADMIN_UNBOUND** — For each `privileged` tier service, if `mesh:admin` is not in its capabilities, emit (`entity_id` = `service_id`, `detail` = **empty**).

## Service trust_boundary_risk field

Allowed values only: `none`, `elevated`, `critical`.

- `none` — tier is `internal`
- `elevated` — tier is `partner`
- `critical` — tier is `privileged`

`ADMIN_UNBOUND` does **not** change `trust_boundary_risk`.

## Finding kinds

`finding_id` = `{scenario_id}::{entity_id}::{event_seq:04d}`.

| Kind | When | `detail` |
|------|------|----------|
| `UNVERIFIED_CALLER` | internal callee without token | empty |
| `PRIVILEGE_ESCALATION` | propagated cap absent on caller | capability |
| `UNTRUSTED_PEER` | no trust edge | caller_id |
| `UNKNOWN_CALLEE` | unknown callee | event kind |
| `UNKNOWN_CALLER` | unknown caller / BIND target | event kind |
| `DUPLICATE_SERVICE` | second REGISTER_SERVICE | empty |
| `DUPLICATE_TRUST` | duplicate ALLOW_TRUST | from_service |
| `LATERAL_MOVEMENT` | cross-actor propagation | capability |
| `RESTRICTED_ESCALATION` | blocked partner→privileged | callee_id |
| `MESH_ASYMMETRY` | missing reciprocal internal→partner edge | partner service_id |
| `OPEN_PRIVILEGE_PATH` | privileged lacks mesh:audit with partner inbound | partner service_id |
| `ADMIN_UNBOUND` | privileged lacks mesh:admin | empty |

Sort `findings` by `finding_id` ascending. `status` = `VALID` iff no findings.

Across all bundled scenarios together, the report must use every kind at least once.

## Build and allowed paths

Use `make build` and `make run` only. The Go binary must live at `/app/build/trustbound` (`go build -o build/trustbound`). Do not leave `/app/trustbound` or other stray top-level binaries.

## Report

Write `/app/build/service_trust_boundary_report.json` per `/app/docs/SCHEMA.md`. UTF-8 compact JSON, LF only, exactly one trailing newline; use `[]` never null. Identical `/app/data` bytes must produce byte-identical reports across consecutive `make run` invocations.
